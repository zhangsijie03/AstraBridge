# AstraBridge · 星桥 0.5.17

本版本取消星桥与客户端之间的单模型绑定，切换模型时不再需要同时操作星桥。

## 更新

- 网关同时暴露 `gpt-6-astra` 与 `gpt-6.1-sol`，每次请求按 `model` 字段动态路由。
- `/v1/models` 返回两个受支持模型，客户端可直接在 AiMaMi/Codex 中切换。
- 星桥界面的模型选择仅用于“测试连接”，不再决定实际聊天转发模型。
- 继续拒绝其它模型，并保留 6.1 Sol 的原生 `none/minimal` 推理档位限制。

## 验证

- Go 全量测试、竞态检测和 `go vet`
- macOS UI 契约、构建、离线 smoke、签名和 ZIP 校验
- Windows 协议 smoke 与发布构建由 GitHub Actions 执行

本地测试未使用真实账号访问 BPS；实际模型权限仍取决于当前 ChatGPT 账号的 BPS 授权状态。

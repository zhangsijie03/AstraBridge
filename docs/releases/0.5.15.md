# AstraBridge · 星桥 0.5.15

本版本把 BPS 协议基线更新到 Sub2API `production` 最新提交 `bf9405e4ab58c1be4fc8ec2101371753a016908e`，并保留星桥的原生附件上传、会话缓存隔离和 SSE 文件引用兼容适配。

## 更新

- 同步 Sub2API 最新 BPS 请求、历史消息、图片校验、附件限制和工具示例实现。
- 原生图片处理继续走 BPS 附件接口：不引入公网图床、临时图片路由或平台账号调度。
- 移除已不再使用的“禁用图片时静默替换”兼容分支，避免图片上下文被静默丢弃；星桥固定使用原生图片上传路径。
- 保留星桥本地流式 `output_text` 引用字段保护，以及本地文件引用、代理、账号和自动更新逻辑。
- 上游新增的普通 Codex 模型目录、Prism 会话和服务端图片中继不带入固定 `gpt-6-astra` 本地网关。

## 验证

- `python3 scripts/check_upstream.py`
- 全量 Go 测试、竞态测试和 `go vet`
- macOS / Windows 构建、离线 smoke、签名及发布后更新下载校验

本次仍未使用真实账号向 BPS 发送请求；实际回答质量取决于账号权限、客户端请求内容和上游状态。

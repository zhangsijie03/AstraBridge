# AstraBridge · 星桥 0.5.7

本版本加入跨平台应用内更新，检查到新版本后可直接在星桥内完成下载、校验、替换和重启。

## 应用内更新

- 启动时后台检查 GitHub 最新 Release，并在主窗口与应用菜单提供“检查更新”。
- 下载对应平台 ZIP 与 SHA256SUMS.txt，安装前验证 SHA-256；网络失败、发行包不完整或校验失败时保留当前版本。
- macOS 与 Windows 使用独立更新进程等待主程序退出，再替换应用文件并自动重启。
- 更新全程在应用内完成，不打开浏览器，也不要求用户手动下载、解压或替换程序文件。
- 保留现有账号、连接配置和本地状态目录；不会上传 API Key、账号凭据、请求内容或本地文件。

## 构建验证

- macOS Swift UI 类型检查与 UI JSON 契约测试通过。
- Windows 更新逻辑随 .NET WinForms 项目编译；Windows Desktop 引用和运行时包由 CI runner 还原。

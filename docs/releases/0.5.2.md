# AstraBridge · 星桥 0.5.2

本版本将协议核心和主要转发链路对齐到 **Sub2API v2.9.3**，并新增运行转发日志。此前本地测试版通过用户试用，本次提供 macOS 和 Windows 正式发行包。

## 更新内容

- **原生协议升级**：固定上游提交 `faf58e440b1bddb07429f74ed63b570c11d1c0f8`；58 个协议文件和 3 个传输诊断文件原样沿用，另保留 1 个明确标注的图片辅助提取。打包前逐文件校验。
- **转发日志**：查看连接、响应头、图片上传、工具纠错及终止阶段，区分上游接收字节和客户端事件。支持复制、导出和暂停滚动；仅在内存保留最近 1000 条，不记录账号凭据、聊天正文、图片或工具代码。
- **会话与工具兼容**：接入原生工具目录继承和图片上传后的目录快照，完善线程、窗口、会话元数据和后台请求的隔离。
- **图片处理修复**：用户图片走原生附件；工具截图按新版规则保留经过校验的内联格式，支持两种图片混合出现。
- **长连接处理**：恢复原生 SSE 注释心跳，加入 HTTP/2 健康探测。明确的 HTTP 代理 H2 故障只让后续请求临时尝试 H1，不重放本次请求。
- **失败诊断**：保留原生失败、不完整响应及错误事件，日志增加具体终止分类。对明确的加密推理拒绝，按原生规则进行最多一次同账号恢复，不丢弃用户消息、工具结果或压缩历史。
- **纠错边界**：已经输出正文、可见推理摘要或拒绝内容后，不再因未知工具重新生成整段回答。明确 Free 套餐不准入，未知套餐不误判。

## 下载与升级

- macOS 13+ / Apple Silicon：`AstraBridge-0.5.2-macOS-arm64.zip`
- Windows 10/11 / x64：`AstraBridge-0.5.2-Windows-x64.zip`，包含 .NET 运行时。
- `SHA256SUMS.txt`：两个 ZIP 的 SHA-256 校验值。

请先退出旧版，完整解压后运行新版；已有本地地址和 API Key 继续沿用。仍需手动开启中转，模型固定为 **gpt-6-astra**。新版本不包含 gpt-image-2 图片生成通道。

## 验证与边界

Release 工作流在两平台来源校验、Go 测试及竞态检测、构建和离线启动检查通过后发布。自动化验证使用合成账号和本机模拟上游，不发送真实 BPS 请求。用户测试反馈无异常不代表所有网络环境均已验收；模型长时间生成工具参数时，仍可能等待整轮校验。

macOS 为 ad-hoc 签名且未经公证；Windows 未作 Authenticode 签名。运行前可核对仓库来源及校验值。完整抽离边界和审查记录随发行包附带。

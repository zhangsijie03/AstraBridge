# AstraBridge · 星桥 0.5.1

本版本针对 BPS 长连接和重复测试请求进行兼容性修复。

- SSE 等待心跳改为可被客户端解析的 `response.in_progress` 事件，减少长时间工具调用期间的空闲超时。
- 默认上下文压缩阈值提升到 `920000`，保留客户端显式配置。
- 上游 422/401/403 拒绝增加脱敏分类、错误码和字段提示，不返回可能包含请求内容的原始正文。
- “测试连接”改为随机模板和随机校验词，并增加 60 秒本地冷却，避免连续探测触发上游风控。
- 保持固定模型 `gpt-6-astra`、原生图片附件和双平台桌面界面不变。

下载对应平台 ZIP，完整解压后运行。使用 `SHA256SUMS.txt` 校验下载完整性。

macOS 包为 ad-hoc 签名且未经公证；Windows 包未作 Authenticode 签名。自动化验证不使用真实账号，真实上游连通性仍取决于账号权限和服务状态。

# AstraBridge · 星桥 0.5.8

本版本收紧本地文件链接的安全边界，并增强跨平台应用内更新失败时的恢复能力。

## 更新与安全

- Windows 更新器等待旧进程退出后才替换文件；更新包先写入临时目录，并在启动新版本失败时恢复旧目录。
- macOS 与 Windows 在更新器启动失败或引擎无法关闭时清理 staging 临时目录。
- 本地文件链接仅允许文档、文本、代码、常见图片和 PDF；额外拒绝 .config、.kube、.gnupg、.docker 等敏感目录及常见凭据文件名。
- GitHub Release 发布流程支持重复运行：已有 Release 时覆盖同名资产并更新发行说明。

## 构建验证

- Go 全量测试与 go vet 通过。
- macOS Swift UI 编译通过。
- Windows .NET Release 编译通过。
- 上游来源校验、UI 契约和嵌入式日志测试通过。

# AstraBridge · 星桥 0.5.14

对齐 sub2api 最新 BPS 兼容修复，改善带工具和长会话的回答质量。

## 修复

- 根据当前请求实际声明的工具目录生成最多四个合法调用示例，避免模型继续学习固定的旧工具名、错误传输方式或不匹配的参数格式。
- 清理客户端兼容层生成的 `item_<24 位十六进制>` 消息 ID，再发送完整历史；保留原生消息 ID、工具调用 ID 和正文，减少旧会话上下文被 BPS 拒绝或弱化。
- 保留最新 BPS 的原生推理档位映射：`max` / `ultra` 映射为上游支持的 `xhigh`；实际请求的模型仍为固定的 `gpt-6-astra`。

## 验证

- BPS 核心与网关单元测试、全项目 Go 测试、竞态检测、`go vet` 和来源清单校验通过。
- 本次没有使用真实账号发送请求；真实回答质量仍取决于当前账号的 BPS 模型权限、上游状态以及客户端实际发送的推理档位。

# AstraBridge · 星桥 0.5.4

本版本将 BPS 协议更新至 Sub2API v2.9.4，改善限流、取消及其他流内失败的识别和诊断。

## 更新内容

- 61 个原生协议文件和 3 个传输诊断文件按固定提交原样同步，保留已标注的图片辅助提取文件。
- 使用原生 UpstreamFailure 统一区分限流、鉴权、权限、请求错误和服务器错误；移除 0.5.3 的自定义 SSE 限流观察器。非流式返回相应错误状态，已开始的流保持实际 HTTP 200 和原生失败事件。
- 上游发送 response.cancelled 后立即结束读取，不等待连接关闭；未知错误使用安全分类，不回显自由文本。已接受的生成不会因失败而自动重放。
- 图片上传、生成、工具纠错和连接测试共享账号级 BPS 冷却；有效 Retry-After 优先，缺省 5 秒，本地调度范围 1–7200 秒。同一引擎停止/启动不清空冷却，退出应用后清空。
- macOS 和 Windows 日志区分实际上游 HTTP 状态、错误分类状态和本地冷却拦截；经校验后记录上游返回的等待时间、剩余额度、用量百分比及重置窗口提示。
- 冷却提示注明来源。上游没有给出有效等待时间时明确显示默认回避，不把 5 秒当作额度恢复时间。纠错使用自身响应的等待提示。
- 同步该原生版本的图片附件引用修复：附件引用只发送 type/file_id，移除上游不支持的附加字段。

## 升级与验证边界

退出旧版后完整解压新版，仍需手动启动中转，固定模型为 gpt-6-astra，保留原有配置。

本地冷却结束只表示允许再次尝试，不保证上游配额恢复；未提供等待时间时仍沿用原生短暂回避，没有增加自动探测、无限重试或绕过限额。提示头是上游该次响应的报告值，不能单凭它判定 BPS 限流原因。上游建议超过本地两小时上限时，请继续遵守上游建议。

本地测试使用合成账号和模拟上游，没有发送真实 BPS 请求。macOS 为 ad-hoc 签名；Windows 包在 macOS 交叉编译，尚未在 Windows 实机运行。本次提供本地测试包，尚未发布 GitHub Release。

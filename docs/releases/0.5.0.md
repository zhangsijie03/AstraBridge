AstraBridge · 星桥首个 macOS / Windows 双平台版本。

- 新增 Windows 10/11 x64 原生桌面界面，自带 .NET 运行时，完整解压即可使用。
- macOS 13+ Apple Silicon 版继续保留原生界面及已有地址、Key。
- 两个平台共用 Go 引擎，支持手动启停、圆形 ▶/■ 按钮、连接测试、地址/Key/固定模型复制。
- 固定模型为 `gpt-6-astra`；内置 BPS 原生图片附件上传，无需图床。
- 修复 Windows 进程锁和数据目录兼容，关闭窗口时取消等待中的引擎请求。
- 补充开源 README、构建流程、许可证及精确上游来源。

下载对应平台 ZIP，完整解压后运行。`SHA256SUMS.txt` 可用于校验下载完整性。

macOS 包为 ad-hoc 签名且未经公证；Windows 包未作 Authenticode 签名，可能显示发布者未知提示。本项目是社区协议适配，不保证账号具备 BPS 权限或提高模型质量。自动化验证不使用真实账号，真实上游连通和视觉结果未验收。

# AstraBridge · 星桥 0.5.6

本版本针对长时间 Responses 请求和本地文件引用稳定性进行修复，提供 macOS Apple Silicon 测试包。

## 连接稳定性

- 将星桥网关单次 Responses 请求总时限从 20 分钟延长至 60 分钟，避免长工具链超过 20 分钟后触发重连。
- 本地 provider 配置模板同步使用 3,600,000 毫秒的流空闲时限。
- 保留 15 秒 SSE 保活和 0 次自动重放，避免对工具调用或其他有副作用请求重复执行。

## 本地文件引用

- 将本地文件引用转换为受保护的本地 HTTP 只读链接，兼容只允许 http/https 的客户端。
- 保留 Responses 的 output_text、annotations、logprobs 和 file_citation 元数据。
- 文件链接带进程内令牌和有效期，仅允许用户目录与临时目录中的安全文件，禁止敏感目录和写入操作。

## 验证

- 来源清单支持登记并校验本地适配文件和本地回归测试。
- Go 全仓编译检查、连接时限回归测试、文件引用定向测试和 arm64 应用签名校验通过。

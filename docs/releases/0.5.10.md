# AstraBridge · 星桥 0.5.10

本版本修复 macOS 应用内自动更新在“更新已准备”状态持续加载、无法关闭并重新打开的问题。

## 自动更新

- 更新关闭应用时优先向本地引擎发送明确的 quit 命令，先停止本机中转服务并结束后台进程。
- 应用关闭请求增加超时兜底：后台进程异常时先发送终止信号，仍未退出时强制结束，避免更新器永久等待旧 PID。
- 更新器记录替换与重启日志，并在旧应用超过 30 秒未退出时自动清理进程后继续更新。
- Go 端 quit 即使监听器已被并发关闭也会结束主进程，确保 macOS 更新器能够继续替换并重新打开应用。

## 验证

- Swift macOS UI 编译通过。
- UI 契约与嵌入式日志检查通过。
- Go 全量测试、race、vet 与跨平台打包由 GitHub Actions 执行。

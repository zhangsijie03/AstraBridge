# AstraBridge · 星桥 0.5.16

本版本在保留 Astra 默认兼容行为的同时，新增 `gpt-6.1-sol` 路由支持，并同步 macOS / Windows 模型选择与协议校验。

## 更新

- 支持 `gpt-6-astra` 与 `gpt-6.1-sol`，启动中转或测试连接前可在桌面端选择模型。
- 网关、`/v1/models`、引擎命令和两端 UI 共用同一模型白名单，拒绝其它模型，运行中锁定当前选择。
- 保留 Astra 的 `none/minimal → low` 兼容转换；6.1 Sol 按 Sub2API 原生规则拒绝 `none/minimal`，避免静默改变推理请求。
- 补充 6.1 Sol 的请求透传、状态事件、模型列表和推理档位回归测试。

## 验证

- `python3 scripts/check_upstream.py`
- Go 全量测试、竞态测试和 `go vet`
- macOS UI 契约、构建、离线 smoke、签名和 ZIP 校验
- Windows 协议 smoke 与发布构建由 GitHub Actions 执行

本地测试未使用真实账号访问 BPS；实际模型权限仍取决于当前 ChatGPT 账号的 BPS 授权状态。

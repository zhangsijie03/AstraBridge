# AstraBridge · 星桥 0.5.9

本版本修复本机代理长连接中断后的连续重连问题，提升通过本地代理访问 BPS 时的稳定性。

## 连接稳定性

- 本机 127.0.0.1、localhost 和 ::1 代理默认使用 HTTP/1.1，避免代理对 BPS HTTP/2 长连接重置导致流中断。
- 上游连接失败和响应流提前中断时增加 2–30 秒指数退避，并返回 Retry-After，避免 AiMaMi 在代理故障期间快速重复请求。
- 上游恢复并返回有效响应后自动清除退避窗口；已开始的流仍不会自动重放，避免重复执行工具调用或产生副作用。

## 验证

- Go 全量测试与 go vet 通过。
- 新增本机代理协议选择、指数退避和连续失败拦截测试。

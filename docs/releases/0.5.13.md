# AstraBridge · 星桥 0.5.13

修复第三轮审查确认的结构化输出、代理优先级、引用空白和帮助文案问题。

## 升级提示

0.5.12 可直接在应用内检查更新并升级。**Windows 0.5.11 及更早版本若安装目录中存有个人文件，请先备份，退出旧版后手动解压覆盖一次。** 这一步仍由旧更新器执行，不能提前获得新版本的文件保护修复。

## 修复

- `json_object` / `json_schema` 输出保留原生校验后的内容，不再执行 Markdown 文件链接改写，避免产生非法 JSON 转义或破坏 Schema 的 const、enum 等约束。流式和非流式请求都适用。
- 普通文本仍生成安全文件链接；引用位置末尾带空格、Tab 或换行时可以正常解析，文件名内部空格保持原样。
- macOS 引擎与更新器共享显式代理选择顺序：`HTTPS_PROXY`、`https_proxy`、`HTTP_PROXY`、`http_proxy`。显式环境配置优先，不再被系统代理覆盖；引擎只在未配置时补充系统静态 HTTPS 代理，没有内置固定代理地址。
- macOS / Windows 接入帮助准确说明 JSON / JSON Schema 支持方式：通过提示约束并在本地校验，不提供上游原生约束解码。

## 验证

- 新增完整网关回归：流式与非流式的 JSON、JSON Schema、普通文本及默认格式；核对增量、结束快照、事件序号和文件授权边界。
- 引用外围空白及文件名内部空格测试，覆盖每个字符分段位置。
- 代理优先级、大小写变量、HTTP 后备、系统后备、环境保留及本地 HTTP CONNECT / SOCKS5 握手测试。
- Go 全量 race、vet、来源校验；macOS 界面、更新回滚、真实退出与重启、打包 smoke 和签名检查；发布 CI 验证 macOS 与 Windows 后上传两端 ZIP 和 SHA256SUMS.txt。

本轮功能验证使用合成请求、临时文件和本地模拟服务，不读取真实账号、不请求真实 BPS。结构化输出中的文件引用保留原文；本次未扩展 Office 文件格式支持。

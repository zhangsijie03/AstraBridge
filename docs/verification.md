# 验证范围

所有自动化测试仅使用合成账号、合成图片和本机模拟上游。不使用真实账号完成 BPS 连通、图片上传或模型质量验收。

## 通用引擎

- 原协议测试与 26 个锁定源码文件的 SHA-256 校验。
- 本地 API Key 校验、回环监听、Host/Origin 检查、账号隔离、固定模型、流式事件和取消。
- 工具回放、线程作用域、响应错误与心跳。
- 原生图片预校验、附件上传、缓存隔离、去重、大小/像素上限、超时及资源预算。
- 配置跨重启保留、损坏配置拒绝、旧版本备份安全恢复。
- 进程锁独占、释放与保留文件；stdin EOF 在探测时取消并退出。

执行 `go test -mod=vendor -race -count=1 ./...` 与 `go vet -mod=vendor ./...`。

## 平台验证

macOS：Swift/Go 字段契约、AppKit 编译、打包引擎离线启动/退出、签名检查和 ZIP 完整性。

Windows：Go 测试、WinForms 构建、打包 UI 的离线 smoke 检查、引擎启动/退出及 JSON 契约。Windows 没有 Unix SIGINT 子进程语义，对应测试改由 stdin EOF 覆盖；权限测试检查 Windows 行为，不假设 POSIX 0600 等于 ACL。

具体版本的执行结果以 GitHub Actions 日志为准。单纯交叉编译不能代替目标平台运行；自动化检查也不能代替全部 DPI、辅助功能和真机网络环境的人工验收。

## 验收边界

本地服务启动、模型列表和离线检查通过，不代表账号具备 BPS 权限。未验证真实上游视觉结果，不能声称模型质量有所提高。

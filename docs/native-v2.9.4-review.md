- HTTP 200 后流内 429、显式状态与 code 冲突、仅有 error.type、鉴权/权限/服务端错误和未知标识。
- 上游取消后不关闭连接时立即结束；失败不触发请求重放，待校验工具不得泄漏。
- HTTP 429、图片上传和纠错限流；账号隔离、令牌刷新、并发冷却、过期和本地拦截。
